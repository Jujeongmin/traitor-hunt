# P6: 오픈월드 RPG 전환

결정일 2026-09-21. 배신자·투표 게임은 동시 접속자가 부족하면 성립하지 않는다(봇으로 채운 판은 재미가 없다).
혼자서도, 여럿이서도 되는 오픈월드 RPG로 바꾼다. 배신자 모드는 삭제한다.

## 결정

| 항목 | 결정 |
|---|---|
| 월드 | 마을(안전지대·상점·퀘스트) → 숲 필드 1 → 숲 필드 2 → 보스 구역. 구역마다 따로 도는 채널(Verse8 방) |
| 채널 인원 | 최대 20명. 차면 새 채널 |
| 성장 | 사냥·레벨업, 장비·인벤토리, 퀘스트, 직업 스킬 |
| 결제 500 VX | 무료: 마을 + 필드 1 + 레벨 10까지. 구매: 필드 2·보스 구역·레벨 제한 해제 |
| 전투 | 지금의 3인칭 검·방패 근접전과 막기를 그대로 쓴다 |

## Verse8에서의 현실

- 수백 명이 한 세계에 있는 MMO는 아니다. 구역 × 채널로 나눠서 한 방에 최대 20명.
- 지금은 한 사람의 브라우저(호스트)가 몬스터를 움직인다. 사람이 드나드는 필드에서는 서버가 방 틱(`$roomTick`)에서
  몬스터를 움직인다. 틱 주기와 서버 비용은 실측하며 맞춘다.
- 캐릭터(레벨·경험치·골드·인벤토리·장비·퀘스트·스킬·마지막 위치)는 계정의 userState에 저장한다. 이 데이터는
  계정 ID를 아는 누구나 읽을 수 있다(docs/VERSE8-EDITOR.md) — 비밀이 없는 데이터만 둔다.

## 삭제하는 것

배신자·빙의·투표 발판, 목표 단계(광석 → 나무 문 → 룬 선돌 → 제단 → 탈출), 로비·매치메이킹·봇 채우기,
매치 결과와 그 기반의 전적·랭킹(랭킹은 레벨 기준으로 다시 만든다), 연습 모드의 봇 동료.

## 남기는 것

계정·닉네임, 친구·파티(같은 채널로 모이기에 쓴다), 3인칭 카메라·이동·점프·발판, 근접전·막기·직업,
캐릭터 꾸미기(파츠), 레벨·경험치 규칙, 야외 렌더러(숲·바위·하늘), 결제(구매 기록·중복 방지), 배경음 구조.

## 단계

1. **토대**: 배신자 매치 계통 삭제. 구역 정의(격자 맵 여러 장), 채널 입장·이동, 구역 안 위치 동기화, 캐릭터 저장.
   메뉴의 "게임 시작" → 마지막으로 있던 구역의 채널로 입장.
2. **사냥**: 서버가 구역마다 몬스터를 스폰·리스폰하고 방 틱에서 AI를 돌린다. 처치 경험치, 레벨업 능력치(체력·공격),
   사망하면 마을에서 부활.
3. **장비**: 드롭·골드·인벤토리 화면, 장비가 능력치를 바꾼다. 마을 상점.
4. **퀘스트**: 마을 NPC, 퀘스트 목록, 사냥·수집·보스 퀘스트와 보상.
5. **스킬**: 직업별 액티브 스킬 2~3개와 재사용 대기시간.
6. **결제 구간**: 레벨 10·필드 2 잠금과 구매 흐름(지금 것 재사용), 보스 구역.
7. **다듬기**: 미니맵, 파티 UI, 채팅 여부, 모바일 조작.

## 필요한 에셋 (받아야 함)

- 마을 건물·소품(집, 우물, 상점 가판대 등). 지금 받은 Polytope Nature Free에는 울타리·다리 정도만 있다.
- 필드 2·보스 구역용 몬스터 추가(Mini Legion 계열이면 화풍이 맞는다).
- NPC는 모듈형 영웅의 파츠 조합으로 우선 만든다.
